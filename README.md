# CECyTEJ 3.º B — Juegos Mexicanos

¡Bienvenido a nuestro proyecto!

Esta página web fue creada por alumnos de **3.º B del Colegio de Estudios Científicos y Tecnológicos del Estado de Jalisco (CECyTEJ)** para presentar dos juegos educativos: Verdadero o Falso Mexicano y Basta Mexicano.

## 📁 Instalación y organización de archivos

Para que la página funcione correctamente después de descargar el proyecto, es necesario organizar los archivos de la siguiente manera:

### 1. Crear las carpetas

Dentro de la carpeta principal del proyecto, crea dos carpetas adicionales con estos nombres exactos:

- `css`
- `js`

### 2. Organizar los archivos

Coloca cada archivo en su carpeta correspondiente:

```text
CECyTEJ/
│
├── index.html
│
├── css/
│   └── styles.css
│
└── js/
    └── script.js
```

### 3. Abrir la página

Una vez organizados los archivos:

1. Guarda todos los cambios.
2. Abre el archivo `index.html` en tu navegador.
3. ¡Listo! Ya podrás visualizar la página web.

## 🛠️ Tecnologías utilizadas

- HTML5: estructura de la página.
- CSS3: diseño, colores y estilos.
- JavaScript: funcionamiento del menú de navegación.

## 🎮 Juegos incluidos

**Verdadero o Falso Mexicano:** dinámica de preguntas sobre la cultura, historia y tradiciones de México.

**Basta Mexicano:** juego de palabras en el que los participantes deben encontrar respuestas relacionadas con México utilizando diferentes categorías y letras.
